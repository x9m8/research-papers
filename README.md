## What each folder contains

- `paper/`: the PDF of the paper.
- `code/`: scripts that rebuild every result, in the order given in the folder's README.
- `results/`, `figures/`, `manuscript/`: outputs and the manuscript source.
- `audits/`: the two independent checks each paper went through before publication (numbers and citations).
- `README.md`: data sources with links, licences, what is not redistributed and how to run the code.

Raw data that may not be redistributed, or that is too large, is not included; each folder's README says where to download it.
