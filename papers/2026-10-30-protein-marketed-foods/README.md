# Protein-marketed packaged foods: reproducibility package

Kalafatis, P. (2026). *Paying for protein: protein-named US packaged foods, nutrients and breakeven prices* [Preprint, not peer reviewed, version 1]. x9m8.com.

## Contents
- `code/` (Python 3.13 with pandas, NumPy, SciPy and matplotlib; run in this order)
  - `00_browser_extract.js`: the JavaScript that read the official FoodData Central zip in a browser tab and wrote the four extract files in `data/raw/` (see "How the data were obtained").
  - `common.py`: paths, the pre-specified name rules (E1, E2), ingredient marker patterns, package-weight parser, whole-food benchmark definitions.
  - `01_prepare.py`: US, not-discontinued, latest record per GTIN (leading-zero variants collapsed), 34 categories with at least 20 protein-named products, plausibility filters, derived outcomes → `data/derived/products.pkl`, `results/sample.json`.
  - `02_validation_sample.py`: random sample of 300 protein-named products for manual coding → `results/validation_sample.csv`; the codes are in `data/handcoded_validation.csv`.
  - `03_composition.py`: Part A (E3 eligibility, within-category contrasts C1 with bootstrap CIs and an energy-density-stratified sensitivity, brand-line twins C2 with Wilcoxon tests and Holm correction, added-sugar post-2023 sensitivity) → `results/composition.json`, `results/twin_groups.csv`.
  - `04_prices.py`: Part B (whole-food cost per gram of protein; breakeven package and serving prices; breakeven premium for twins) → `results/prices.json`, `results/whole_food_benchmarks.csv`, `results/breakeven_products.csv.gz`, `results/twin_groups_ratio.csv`.
  - `05_grocerydb_check.py`: external check of the breakeven thresholds against observed 2021 shelf prices of protein-named items in GroceryDB → `results/grocerydb_check.json`. Needs `data/external/GroceryDB_foods.csv` (see below).
  - `figures.py`, `graphical_abstract.py`, `tables.py` (rewrites the `## Tables` section of the manuscript), `style.py`.
- `results/` (JSON and CSV results; `log_03.txt`, `log_04.txt` are console output), `figures/` (fig1–fig3 as 300 dpi PNG and PDF; `graphical_abstract.png`, 900 × 420 px), `manuscript/` (`manuscript.md` and `patch_docx.py`), `out/` (Word and PDF built by `../build_docs.sh`: pandoc → `patch_docx.py` → LibreOffice).
- `data/derived/` is regenerated by `01_prepare.py`; `data/handcoded_validation.csv` holds the manual codes for the validation sample.

### How the data were obtained
The build environment could not reach fdc.nal.usda.gov from the command line. The zip was therefore read in a Chrome tab on the FDC site with `00_browser_extract.js`: latest record (maximum `fdc_id`) per `gtin_upc`; description from `food.csv`; nutrients 1003, 1004, 1005, 1008, 1093, 1235, 2000, 1258, 1079, 1253 and 1257 from `food_nutrient.csv`. Records were kept if their category had at least 20 US, not-discontinued products with "protein" in the description, brand or sub-brand (34 categories), or if their own name contained "protein". The gzipped extracts were moved to the analysis machine in chunks through the author's website media library and reassembled byte for byte (file sizes checked). The counts in the release (1,999,950 rows; 465,110 GTINs) match an independent count made during scoping.

## Run
    cd code && python3 01_prepare.py && python3 02_validation_sample.py && python3 03_composition.py > ../results/log_03.txt && python3 04_prices.py > ../results/log_04.txt && python3 05_grocerydb_check.py > ../results/log_05.txt && python3 figures.py && python3 graphical_abstract.py && python3 tables.py
    bash ../../build_docs.sh   # Word and PDF; needs pandoc, python-docx and LibreOffice

Random seed 20261022. `03_composition.py` takes about four minutes (bootstrap, 1,000 replicates). A full rerun on 28 October 2026 reproduced `composition.json` exactly.

## Notes and limits
- Exposure is the product *name* (description, brand, sub-brand), not front-of-pack claims, which FDC does not record.
- No product prices are used or reported. Part B gives the price at which a product would match whole foods on cost per gram of protein.
- Validation codes were assigned by the AI assistant under the author's direction, using the rule written in the manuscript, and re-read in a second pass; a second independent human coder was not used.
- Whole-food prices: BLS series APU0000708111 (eggs), APU0000709112 (whole milk), APU0000714233 (dried beans), APU0000FF1101 (chicken breast), and for context APU0000FJ1101, APU0000703112, APU0000703113, APU0000710212, APU0000FJ4101, APU0000702111, APU0000701312; October 2025 to September 2026 (no October 2025 value published). Composition: SR Legacy fdc_ids listed in `code/common.py`.
- Licences: FoodData Central data are public domain under CC0 1.0 Universal (stated in the FDC API guide, https://fdc.nal.usda.gov/api-guide); BLS data are in the public domain; GroceryDB is MIT-licensed.
